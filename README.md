# slotpack

Slot CSV/TSV pack tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/slotpack/

## Install / run

```bash
git clone https://github.com/theworker02/slotpack.git
cd slotpack
node src/cli.js
node --test
```
